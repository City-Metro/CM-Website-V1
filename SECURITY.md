# Security Policy

City Metro is a fictional transportation brand, but its websites, accounts and
related systems are real and operational, so we take security reports seriously.

## Supported Versions

This repository (`cm-website-v1`) is the City Metro website. Only the latest
version deployed from the `main` branch receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.x (latest) | :white_check_mark: |
| Older commits and branches | :x: |

## Reporting a Vulnerability

Please report vulnerabilities by emailing **felix@citymetro.xyz** with as much
detail as you can: what you found, where, steps to reproduce, and the potential
impact. Please do not open a public GitHub issue for security problems.

What to expect:

- **Acknowledgement:** we aim to reply within 3 business days.
- **Updates:** we aim to send a status update at least every 7 days while the
  report is being investigated.
- **If accepted:** we will work on a fix, tell you when it is deployed, and
  credit you if you would like.
- **If declined:** we will explain why, for example if it is out of scope, not
  reproducible, or not a security issue.

## Scope

In scope: the City Metro website in this repository and its deployed pages.

Out of scope: third-party services we use (Cloudflare, Noupe, HubSpot, Google,
Oracle Cloud), social engineering, spam, and denial-of-service testing.

## Good-Faith Research

We will not pursue action against researchers who act in good faith, follow this
policy, avoid accessing or changing other people's data, and give us reasonable
time to fix an issue before disclosing it publicly. This policy is the
published security policy referred to in the City Metro Terms of Service.

Thank you for helping keep City Metro safe.
